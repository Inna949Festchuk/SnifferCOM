## 🔗 Dual Sniffer: работа с двумя устройствами одновременно

Скрипт `dual_sniffer.py` обеспечивает параллельный опрос двух устройств с синхронизацией потоков данных.

### 📊 Характеристики
| Параметр | Значение |
|----------|----------|
| Частота геопозиционера | 200 Гц (чистый CSV) |
| Частота GPS+компас | 10 Гц (NMEA-0183 + ;X,Y,Z) |
| Выходная частота | 200 Гц (интерполяция магнитных данных) |
| Окно синхронизации | ±25 мс (настраивается) |
| Интерполяция | Линейная, по сырым осям X,Y,Z |

### 🚀 Запуск
```bash
# Базовый запуск
python3 dual_sniffer.py --geo-port /dev/ttyUSB0 --mag-port /dev/ttyACM0 --output data.jsonl

# С учётом магнитного склонения и кастомных смещений датчиков
python3 dual_sniffer.py --declination 12.5 --offsets 0,1.5,3.0,4.5 --output stream.jsonl

# Просмотр первых 10 записей из сохранённого файла
head -n 10 data.jsonl | python3 -m json.tool

# Загрузка в pandas для анализа
# python3 -c "import pandas as pd; df = pd.read_json('data.jsonl', lines=True); print(df.head())"
```
