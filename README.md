# 🛰️ SnifferCOM v4.1 — Магнитометрическая коса с геодезической привязкой

Система для синхронного сбора данных с **4-датчиковой сенсорной косы** (200 Гц) и **GPS+компас** (10 Гц) с расчётом точных координат каждого датчика в реальном времени.

> ✅ Работает **полностью офлайн** после установки  
> ✅ Прямая геодезическая задача на эллипсоиде WGS84  
> ✅ Автоматический расчёт магнитного склонения (модель WMM2020)  
> ✅ Веб-карта с автообновлением (CartoDB, масштаб до 1:500)

---

## 📐 Теория работы

### 1. Геометрия сенсорной косы
```
  Направление движения (курс α)
                ↑
                │
      ┌─────────┴─────────┐
          Сенсорная коса        
      ├────┬────┬────┬────┤
     [S1] [S2] [S3] [S4]          ← 4 физических датчика
      │    │    │    │
   -45см -15см +15см +45см         ← Шаг 30 см, вынесена на +1.0 м вперёд
               │
             [GPS]                 ← Антенна в центре (0,0)
```  

- **Коса перпендикулярна курсу**: угол между вектором движения и линией датчиков = 90°
- **Локальная система координат**: 
  - `dx` — смещение вперёд по курсу (м)
  - `dy` — смещение влево/вправо поперёк курса (м, +влево)

### 2. Прямая геодезическая задача
Для каждого датчика решается уравнение на эллипсоиде WGS84:

```
Дано:
  • Точка старта: (lat_gps, lon_gps)
  • Пеленг: β = α + arctg(dy/dx)  [градусы]
  • Расстояние: d = √(dx² + dy²)  [метры]

Решение (алгоритм Karney):
  (lat_sensor, lon_sensor) = Geodesic.Direct(lat_gps, lon_gps, β, d)
```

**Точность**: ~15 нанометров (на 9 порядков точнее погрешности бытового GPS).

### 3. Магнитное склонение (офлайн)
Азимут компаса — **магнитный**. Для привязки к карте нужен **истинный**:

```
azimuth_true = azimuth_magnetic + declination
```

**Declination** рассчитывается встроенной моделью **WMM2020** (World Magnetic Model):
- Учитывает координаты (lat, lon) и год
- Точность: ±0.3° глобально
- Не требует интернета или внешних файлов

### 4. Синхронизация потоков
| Устройство | Частота | Роль |
|------------|---------|------|
| **GPS+компас** (`/dev/ttyACM0`) | 10 Гц | **Мастер**: формирует ритм пакетов, даёт координаты и курс |
| **Сенсорная коса** (`/dev/ttyUSB0`) | 100–200 Гц | **Слейв**: постоянно обновляет буфер показаний |

**Стратегия**: при приходе валидного GPS-кадра берётся **последнее доступное** состояние всех 4 датчиков. Рассинхрон ≤10 мс → смещение ≤1 см при 4 км/ч (пренебрежимо мало).

## 📦 Установка

### 🐧 Linux (Ubuntu/Debian)
```bash
# 1. Клонирование репозитория
git clone <url-репозитория>
cd SnifferCOM

# 2. Виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Права на порты (опционально)
sudo usermod -aG dialout $USER  # добавить пользователя в группу
# После этого — перезайти в систему
```

### 🪟 Windows (PowerShell)
```powershell
# 1. Клонирование
git clone <url-репозитория>
cd SnifferCOM

# 2. Виртуальное окружение
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. Зависимости
pip install -r requirements.txt

# 4. Права на COM-порты
# Обычно не требуются. Если доступ запрещён — запустить PowerShell от имени Администратора
```

## 🔌 Порядок подключения датчиков

1. **Физическое подключение**:
   ```
   [Сенсорная коса] --USB--> /dev/ttyUSB0  (Linux)  или  COM3  (Windows)
   [GPS+компас]     --USB--> /dev/ttyACM0 (Linux)  или  COM4  (Windows)
   ```

2. **Порядок в протоколе** (бинарный кадр 23 байта):
   | Байт | Поле | Значение |
   |------|------|----------|
   | 0 | Синхро | `0x00` |
   | 1 | **Индекс датчика** | `01`, `02`, `03`, `04` |
   | 2 | Адрес отправителя | `0x01` |
   | 3 | Синхро | `0xFF` |
   | 4–6 | Служебные | модуль, команда, фильтр |
   | **7–10** | **Абсолютное значение** | `int32 LE`, нТл × 10 |
   | **11–14** | **Градиент** | `int32 LE`, нТл/м × 10 |
   | 15–16 | Длина | `uint16 LE` |
   | 17–18 | CRC-16 | контрольная сумма |
   | 19–22 | Маркер | `0x12345678 LE` |

3. **Важно**: датчики должны быть подключены к контроллеру **в порядке 1→2→3→4**, иначе матрица смещений применится неверно.

## 🚀 Запуск проекта

### 🐧 Linux (3 терминала)
```bash
# Терминал 1: Основной скрипт (сбор данных)
python3 dual_sniffer_v4_1.py \
  --sensor-port /dev/ttyUSB0 \
  --gps-port /dev/ttyACM0 \
  --output field_data.jsonl \
  --forward-offset 1.0 \
  --spacing 0.3 \
  --debug-geometry

# Терминал 2: Веб-сервер для карты
python3 serve_map.py

# Терминал 3: Открыть карту в браузере
firefox http://localhost:8000/map.html
# или
google-chrome http://localhost:8000/map.html
```

### 🪟 Windows PowerShell (3 окна)
```powershell
# Окно 1: Основной скрипт
python dual_sniffer_v4_1.py `
  --sensor-port COM3 `
  --gps-port COM4 `

# Окно 2: Веб-сервер
python serve_map.py

# Окно 3: Открыть карту

```

### 🔧 Описание флагов
| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--sensor-port` | `/dev/ttyUSB0` | Порт сенсорной косы (200 Гц, бинарный протокол) |
| `--gps-port` | `/dev/ttyACM0` | Порт GPS+компас (10 Гц, NMEA-0183) |
| `--sensor-baud` | `115200` | Скорость порта косы |
| `--gps-baud` | `9600` | Скорость порта GPS |
| `--forward-offset` | `1.0` | Вынос косы вперёд от GPS (метры) |
| `--spacing` | `0.3` | Шаг между датчиками поперёк курса (метры) |
| `--declination-override` | `None` | Принудительное склонение (переопределяет WMM2020) |
| `--debug-geometry` | `False` | Выводить расчётные смещения в метрах в консоль |
| `--output`, `-o` | `None` | Путь к выходному JSONL-файлу |

## 🗺️ Работа с картой

1. **Запустите** `serve_map.py` (открывает `http://localhost:8000`)
2. **Откройте** `http://localhost:8000/map.html` в браузере
3. **Наблюдайте**:
   - 🔴 Красный маркер — антенна GPS
   - 🔵 Четыре синих маркера — датчики косы
   - 🟠 Пунктирная линия — ось косы (должна быть ⟂ курсу)
   - 🟢 Зелёная стрелка — направление движения
   - 🟣 Фиолетовый след — трек последних 100 позиций

### 🔍 Масштабирование
- Колесо мыши — зум
- Два пальца на тачпаде — панорамирование
- Кнопки `+`/`–` — зум
- **Рекомендуемый масштаб**: 1:500 – 1:2000 (видно каждый метр)


## 🔘 Как работает кнопка «Пауза/Старт»

| Режим | Поведение карты |
|-------|----------------|
| **▶️ Старт** (по умолчанию) | Карта автоматически центрируется на новых координатах, зум подбирается под все датчики. Данные обновляются. |
| **⏸️ Пауза** | Автоцентрирование **отключено**. Вы можете: <br>• Масштабировать колесом мыши или кнопками `+`/`–` <br>• Перемещать карту мышью <br>• Данные продолжают обновляться (маркеры двигаются), но карта не "прыгает" |

### 💡 Подсказки:
- Кнопка меняет цвет: 🔵 синий = активен, 🟢 зелёный = пауза
- Статус внизу панели показывает текущий режим
- Чтобы вернуться к авто-слежению — нажмите кнопку ещё раз

Теперь вы можете:

2. Открыть карту
3. Нажать **⏸️ Пауза**, чтобы приблизить участок трассы
4. Изучить детали с помощью `+`/`–` или колёсика мыши
5. Нажать **▶️ Старт**, чтобы вернуться к авто-слежению


### ⚠️ Если карта не обновляется
1. Проверьте, что `dual_sniffer_v4_1.py` пишет в `field_data.jsonl`
2. Убедитесь, что `serve_map.py` запущен и не выдал ошибку
3. Откройте **Консоль разработчика** (F12) → вкладка Network → проверьте статус `field_data.jsonl` (должен быть 200)

## 🛠️ Диагностика и частые проблемы

| Симптом | Возможная причина | Решение |
|---------|------------------|---------|
| `Permission denied: /dev/ttyUSB0` | Нет прав на порт | `sudo usermod -aG dialout $USER` + перезайти |
| `parsed: 0, errors: >1000` | Рассинхрон бинарного потока | Проверить, что эмулятор шлёт ровно 23-байтные кадры |
| Карта показывает `Ошибка загрузки` | Браузер блокирует `file://` | Запускать **только** через `serve_map.py` (http://) |
| Датчики на карте выстроены вдоль курса | Инвертирован знак `dy` | Проверить порядок подключения датчиков к контроллеру |
| `azimuth_true` "скачет" на месте | Шум компаса без движения | Нормально; при движении усреднится |

## 🔄 Интеграция с Redis (опционально)
Для отправки данных в веб-проект `mygis`:

1. Раскомментируйте в `requirements.txt`: `redis>=4.5.0`
2. В `dual_sniffer_v4_1.py` добавьте в `OutputHandler.write()`:
   ```python
   import redis
   r = redis.Redis(host='localhost', port=6379, db=0)
   r.lpush('sensor:stream', json.dumps(record))
   ```
3. Запустите локальный Redis: `redis-server`
