# 🛰️ SnifferCOM v4.1 — Магнитометрическая коса с геодезической привязкой

Система для синхронного сбора данных с **4-датчиковой сенсорной косы** (200 Гц) и **GPS+компас** (10 Гц) с расчётом точных координат каждого датчика в реальном времени.

> ✅ Работает **полностью офлайн** после установки  
> ✅ Прямая геодезическая задача на эллипсоиде WGS84  
> ✅ Автоматический расчёт магнитного склонения (модель WMM2020)  
> ✅ Веб-карта с автообновлением (CartoDB, масштаб до 1:500)

---

### 📦 Описание проекта
Система синхронного сбора данных с **4-датчиковой магнитометрической косы** (200 Гц) и **GPS+компас** (10 Гц).
*   **Геометрия:** Коса вынесена на 1 м вперед, датчики расположены перпендикулярно курсу с шагом 30 см.
*   **Расчеты:** Прямая геодезическая задача (WGS84) для координат каждого датчика + расчет истинного азимута (магнитный + склонение WMM2020).
*   **Режим:** Пакетный (10 Гц), триггер от GPS. Данные сенсоров берутся по принципу "последнее доступное".

## 📐 Теория работы

### 1. Геометрия сенсорной косы
```
  Направление движения (курс α)
                ↑
                │
      ┌─────────┴─────────┐
          Сенсорная коса        
      ├────┬────┬────┬────┤
     [S1] [S2] [S3] [S4]          ← 4 физических датчика
      │    │    │    │
   -45см -15см +15см +45см         ← Шаг 30 см, вынесена на +1.0 м вперёд
               │
             [GPS]                 ← Антенна в центре (0,0)
```  

- **Коса перпендикулярна курсу**: угол между вектором движения и линией датчиков = 90°
- **Локальная система координат**: 
  - `dx` — смещение вперёд по курсу (м)
  - `dy` — смещение влево/вправо поперёк курса (м, +влево)

### 2. Прямая геодезическая задача
Для каждого датчика решается уравнение на эллипсоиде WGS84:

```
Дано:
  • Точка старта: (lat_gps, lon_gps)
  • Пеленг: β = α + arctg(dy/dx)  [градусы]
  • Расстояние: d = √(dx² + dy²)  [метры]

Решение (алгоритм Karney):
  (lat_sensor, lon_sensor) = Geodesic.Direct(lat_gps, lon_gps, β, d)
```

**Точность**: ~15 нанометров (на 9 порядков точнее погрешности бытового GPS).

### 3. Магнитное склонение (офлайн)
Азимут компаса — **магнитный**. Для привязки к карте нужен **истинный**:

```
azimuth_true = azimuth_magnetic + declination
```

**Declination** рассчитывается встроенной моделью **WMM2020** (World Magnetic Model):
- Учитывает координаты (lat, lon) и год
- Точность: ±0.3° глобально
- Не требует интернета или внешних файлов

<details>
  <summary> Подробное пояснение: Как работает расчет геометрии косы </summary>  

  #### Шаг 1. Получение сырых данных (X, Y)
  Магнитометр внутри модуля измеряет проекцию магнитного поля Земли на свои оси.
  *   **X** — проекция на продольную ось модуля.  
  *   **Y** — проекция на поперечную ось модуля.
  *   *Важно:* Эти данные приходят в нанотеслах (нТл). Если модуль лежит криво, то X и Y будут измерять поле не там, где нужно.

  #### Шаг 2. Расчет Магнитного Азимута ($\alpha_{mag}$)
  Мы используем функцию `atan2(Y, X)`. Она возвращает угол вектора магнитного поля относительно осей самого датчика.
  $$ \alpha_{raw} = \text{atan2}(Y, X) $$
  Этот угол показывает, где находится **Магнитный Север** относительно корпуса вашего устройства.
  *   Если устройство смотрит точно на Магнитный Север, $\alpha_{raw} = 0^\circ$.
  *   Если устройство смотрит на Восток, $\alpha_{raw} = 90^\circ$.

  #### Шаг 3. Учет Магнитного Склонения (Declination)
  Магнитный Север и Географический (Истинный) Север не совпадают. Разница между ними называется **магнитным склонением**.
  *   Для Калининграда (судя по координатам 54.74, 20.50) склонение составляет примерно **+12.5°** (восточное).
  *   Модель **WMM2020** (World Magnetic Model), встроенная в скрипт, знает, что в точке с такими координатами в 2026 году стрелка компаса отклоняется на 12.5° вправо от истинного севера.

  Формула перехода к истинному азимуту направления корпуса:
  $$ \alpha_{true} = \alpha_{raw} + \text{Declination} $$
  *(Примечание: В коде мы инвертируем логику для получения курса движения, но суть та же: мы корректируем показания компаса на величину местного отклонения поля).*

  > **Почему WMM2020?** Это стандартная модель геофизиков. Она учитывает, что магнитные полюса дрейфуют. Без этой поправки ваша карта была бы повернута на ~12 градусов относительно реального мира.

  #### Шаг 4. Определение Курса Движения
  Теперь мы знаем, куда смотрит нос устройства в системе координат карты (Истинный Азимут). Назовем этот угол **Курс ($\alpha$)**.

  #### Шаг 5. Построение Перпендикуляра (Геометрия Косы)
  По вашему ТЗ, сенсорная коса должна быть **перпендикулярна** курсу движения.
  Представьте, что вы стоите в центре GPS-антенны и смотрите вперед по курсу $\alpha$.
  *   Датчики S1...S4 находятся не перед вами, а сбоку (на линии, перпендикулярной взгляду).
  *   Но вся эта линия смещена от вас на **1 метр вперед** (`dx=1.0`).

  Чтобы найти координаты каждого датчика, мы решаем **Прямую Геодезическую Задачу** для каждой точки:

  1.  **Определяем локальные смещения ($dx, dy$):**
      *   Для всех датчиков $dx = 1.0$ м (вынос вперед).
      *   Для S1: $dy = -0.45$ м (влево).
      *   Для S4: $dy = +0.45$ м (вправо).

  2.  **Считаем пеленг на каждый датчик ($\beta$):**
      Нам нужно знать, под каким углом от Истинного Севера находится каждый конкретный датчик относительно GPS.
      $$ \beta_i = \alpha + \text{arctg}\left(\frac{dy_i}{dx_i}\right) $$
      *   Поскольку коса перпендикулярна курсу, основной угол смещения — это $\pm 90^\circ$.
      *   Функция `arctg(dy/dx)` добавляет небольшую поправку из-за того, что датчики разнесены по ширине косы.

  3.  **Считаем расстояние до датчика ($d$):**
      $$ d_i = \sqrt{dx^2 + dy_i^2} $$
      *   Для крайних датчиков это $\approx 1.097$ м.
      *   Для внутренних $\approx 1.011$ м.

  4.  **Решаем уравнение (Алгоритм Karney):**
      Используя библиотеку `geographiclib`, мы говорим программе:
      > *"Стартуй из точки GPS. Иди по пеленгу $\beta_i$ ровно $d_i$ метров по поверхности эллипсоида WGS84. Где ты окажешься?"*

      Результат этого расчета — точные широта и долгота каждого датчика ($Lat_i, Lon_i$).

</details>

### 4. Синхронизация потоков
| Устройство | Частота | Роль |
|------------|---------|------|
| **GPS+компас** (`/dev/ttyACM0`) | 10 Гц | **Мастер**: формирует ритм пакетов, даёт координаты и курс |
| **Сенсорная коса** (`/dev/ttyUSB0`) | 100–200 Гц | **Слейв**: постоянно обновляет буфер показаний |

**Стратегия**: при приходе валидного GPS-кадра берётся **последнее доступное** состояние всех 4 датчиков. Рассинхрон ≤10 мс → смещение ≤1 см при 4 км/ч (пренебрежимо мало).

## 🔌 Порядок подключения датчиков

1. **Физическое подключение**:
   ```
   [Сенсорная коса] --USB--> /dev/ttyUSB0  (Linux)  или  COM3  (Windows)
   [GPS+компас]     --USB--> /dev/ttyACM0 (Linux)  или  COM4  (Windows)
   ```

2. **Порядок в протоколе** (бинарный кадр 23 байта):
   | Байт | Поле | Значение |
   |------|------|----------|
   | 0 | Синхро | `0x00` |
   | 1 | **Индекс датчика** | `01`, `02`, `03`, `04` |
   | 2 | Адрес отправителя | `0x01` |
   | 3 | Синхро | `0xFF` |
   | 4–6 | Служебные | модуль, команда, фильтр |
   | **7–10** | **Абсолютное значение** | `int32 LE`, нТл × 10 |
   | **11–14** | **Градиент** | `int32 LE`, нТл/м × 10 |
   | 15–16 | Длина | `uint16 LE` |
   | 17–18 | CRC-16 | контрольная сумма |
   | 19–22 | Маркер | `0x12345678 LE` |

3. **Важно**: датчики должны быть подключены к контроллеру **в порядке 1→2→3→4**, иначе матрица смещений применится неверно.

## 🔘 Как работает кнопка «Пауза/Старт»

| Режим | Поведение карты |
|-------|----------------|
| **▶️ Старт** (по умолчанию) | Карта автоматически центрируется на новых координатах, зум подбирается под все датчики. Данные обновляются. |
| **⏸️ Пауза** | Автоцентрирование **отключено**. Вы можете: <br>• Масштабировать колесом мыши или кнопками `+`/`–` <br>• Перемещать карту мышью <br>• Данные продолжают обновляться (маркеры двигаются), но карта не "прыгает" |

### 💡 Подсказки:
- Кнопка меняет цвет: 🔵 синий = активен, 🟢 зелёный = пауза
- Статус внизу панели показывает текущий режим
- Чтобы вернуться к авто-слежению — нажмите кнопку ещё раз

## 📋 Итоговая логика работы (v4.3)

```
1. GPS даёт координаты антенны (lat, lon)
2. Компас даёт магнитный азимут (X, Y → atan2)
3. Склонение считается офлайн через pygeomag (WMM2020)
4. azimuth_true = azimuth_magnetic + declination
5. Для каждого датчика:
   • Рассчитываем пеленг: bearing = azimuth_true + atan2(dy, dx)
   • Решаем прямую геодезическую задачу: (lat_sensor, lon_sensor) = GEOD.Direct(lat, lon, bearing, distance)
6. Результат: 4 точки косы, перпендикулярной направлению движения
```
