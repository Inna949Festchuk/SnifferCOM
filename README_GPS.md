# 🛰️ SnifferCOM-NMEA: Парсер геопозиционера с 3-осевым магнитометром

Скрипт для приёма, валидации и парсинга данных с последовательного порта от устройства геопозиционирования, совмещённого с магнитным компасом. Поддерживает стандарт **NMEA-0183** с пользовательским расширением для сырых данных осей `X, Y, Z`.

---

## 📋 Особенности

| Функция | Описание |
|---------|----------|
| 📡 Приём данных | Неблокирующее чтение из COM/USB порта через `pyserial` |
| 🧭 Парсинг NMEA | Поддержка `$GNRMC`/`$GPRMC` с проверкой контрольной суммы |
| 🌍 Конвертация координат | Автоматический перевод `DDMM.MMMM` → десятичные градусы |
| 🔢 Магнитометр | Извлечение `X, Y, Z`, расчёт азимута и модуля поля |
| 🌐 Магнитное склонение | Учёт локального склонения для точного курса |
| 📊 Статистика | Подсчёт валидных кадров, ошибок парсинга и чексумм |
| 💾 Экспорт | Сохранение результатов в структурированный JSON |

---

## 📦 Формат протокола

Устройство передаёт данные в текстовом виде, завершённые `\r\n`. Основной кадр имеет следующую структуру:

```
$GNRMC,<time>,<status>,<lat>,<N/S>,<lon>,<E/W>,<speed>,<course>,<date>,...,*<CS>;<mag_x>,<mag_y>,<mag_z>\r\n
```

### 📊 Разбор полей

| Часть | Пример | Описание |
|-------|--------|----------|
| `Идентификатор` | `$GNRMC` | Тип сообщения (GNSS Recommended Minimum) |
| `Время` | `184044.60` | UTC время в формате `HHMMSS.ss` |
| `Статус` | `A` | `A` = валидные данные, `V` = предупреждение |
| `Широта` | `5444.50595` | Формат `DDMM.MMMM` (градусы + минуты) |
| `Направление` | `N` | Полушарие: `N` или `S` |
| `Долгота` | `02030.04440` | Формат `DDDMM.MMMM` |
| `Направление` | `E` | Полушарие: `E` или `W` |
| `Скорость` | `1.773` | Скорость над землёй в узлах |
| `Курс (GPS)` | `302.15` | Направление движения по GPS, градусы |
| `Дата` | `270426` | Дата в формате `ДДММГГ` |
| `Чексумма` | `*0B` | XOR-контрольная сумма NMEA-0183 |
| `Разделитель` | `;` | Отделяет стандарт NMEA от расширения |
| `Магнитометр` | `1860,2180,5450` | Сырые значения осей `X, Y, Z` |
| `Завершение` | `\r\n` | Стандартный перевод строки |

> 💡 **Примечание:** Единицы измерения магнитных данных зависят от конкретного датчика (обычно это мкТл, мГс или отсчёты АЦП). Для получения точного курса используется формула `atan2(Y, X)` с компенсацией магнитного склонения.

## 🚀 Использование

Запуск скрипта осуществляется через командную строку:

```bash
python3 validate_sniffer_nmea.py [аргументы]
```

### 🔧 Доступные аргументы

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--port`, `-p` | `/dev/ttyACM0` | Имя последовательного порта (`COM3`, `/dev/ttyUSB0` и т.д.) |
| `--baud`, `-b` | `115200` | Скорость передачи данных (бод) |
| `--max`, `-m` | `∞` | Лимит принимаемых записей (полезно для тестов) |
| `--declination`, `-d` | `0.0` | Магнитное склонение в градусах (восточное `+`, западное `-`) |
| `--output`, `-o` | `None` | Путь к файлу для сохранения результатов в JSON |

### 📝 Примеры запуска

```bash
# Базовый запуск
python3 validate_sniffer_nmea.py --port /dev/ttyACM0

# С учётом магнитного склонения (например, для Москвы ~12.5°)
python3 validate_sniffer_nmea.py --port /dev/ttyACM0 --declination 12.5 --max 50

# Сохранение результатов в файл
python3 validate_sniffer_nmea.py --port /dev/ttyACM0 --output data_nmea.json
```

## 📐 Алгоритмы обработки

### 🌍 Конвертация координат
Формат NMEA `DDMM.MMMM` преобразуется в десятичные градусы по формуле:
```python
decimal_degrees = degrees + (minutes / 60.0)
if direction in ['S', 'W']: decimal_degrees *= -1
```

### 🧮 Расчёт азимута (курса)
Вектор магнитного поля в горизонтальной плоскости проецируется на оси `X` и `Y`:
```python
azimuth = atan2(Y, X)  # в радианах
azimuth = (degrees(azimuth) + declination + 360) % 360
```
> ⚠️ Для высокой точности рекомендуется предварительная калибровка магнитометра (компенсация hard/soft iron искажений).

## ⚠️ Важные замечания

1. **Права доступа:** В Linux может потребоваться `sudo chmod 666 /dev/ttyACM0` или добавление пользователя в группу `dialout`.
2. **Магнитное склонение:** Значение зависит от геолокации и года. Актуальные данные: [NGDC Magnetic Declination Calculator](https://www.ngdc.noaa.gov/geomag/calculators/magcalc.shtml#declination).
3. **Сырые данные:** Значения `X, Y, Z` не откалиброваны. Для навигации в помещении или при наличии металлических помех используется внешняя калибровку.
4. **Совместимость:** Скрипт игнорирует строки, не начинающиеся с `$`, что позволяет работать в смешанных потоках данных.
